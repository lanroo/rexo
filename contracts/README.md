# Contracts

These schemas are the language-neutral boundary of REXO. Version `0.1.0` is
experimental and may change before Core v1.

- `project.schema.json`: project identity and default operating policy.
- `capability.schema.json`: provider-independent outcome contract.
- `workflow.schema.json`: capability-based directed workflow.

Schema URLs reserve the `schemas.rexo.dev` namespace; they are identifiers,
not a claim that the domain is currently serving files.
