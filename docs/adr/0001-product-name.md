# ADR 0001: Use AIOREN as the product name

- Status: superseded by [ADR 0004](0004-rename-to-rexo.md)
- Date: 2026-07-26

> **Superseded.** AIOREN was later found to collide with active AI/agent
> products and channels. The product was renamed to **REXO**. This ADR is kept
> as a historical record of the original decision; see ADR 0004 for the current
> name. Do not reintroduce "AIOREN" in user-facing docs.

## Context

AIOS is already used by a recognized AI Agent Operating System project. AIOX,
AIROS, AILOS, AIONOS, NAiOS, and several close variants also have active,
relevant uses.

## Decision

Use **AIOREN**, expanded as **AI Orchestration Runtime & Economy Network**.
Use `aioren` for the CLI and `github.com/lanroo/aioren` for the Go module.
Historical PDFs may retain AIOS as an architecture codename.

## Consequences

The name aligns with orchestration and the Economy Engine while remaining close
to the original identity. Preliminary web and GitHub searches found no directly
conflicting AI platform. This is not formal trademark clearance; commercial use
requires a professional search in target jurisdictions.
