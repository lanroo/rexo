# Contributing

REXO is in its public-foundation phase. Small, testable changes aligned with
the active roadmap are welcome.

1. Read `REXO_BOOTSTRAP.md` and `REXO_STATE.md`.
2. Open an issue before proposing a new architectural component.
3. Create a focused branch.
4. Run `go test ./...` and `go vet ./...`.
5. Explain compatibility, budget, security, and migration effects.

Architecture grows only when a real, recurring, measurable problem cannot be
solved through existing contracts or extension points.

By contributing, you agree that your contribution is licensed under
Apache-2.0.
